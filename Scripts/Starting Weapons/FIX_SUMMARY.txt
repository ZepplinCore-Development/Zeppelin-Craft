ISSUE 1: Ranged Weapon Class Configuration
-------------------------------------------
PROBLEM: Script was adding ranged weapons to all classes with ranged skills
REQUIRED: Only Hunters, Rogues, and Troll Warriors should get starting ranged

FIX IMPLEMENTED:
  - Added RANGED_ALLOWED_CLASSES = {3, 4} to lib/constants.py (Hunter, Rogue)
  - Added RANGED_ALLOWED_COMBOS = {(8, 1)} to lib/constants.py (Troll Warrior)
  - Updated validate_weapon_coverage() to check configuration before adding ranged

RESULT: ✅ Ranged weapons only added to configured classes


ISSUE 2: Stock Weapon Preference Not Implemented
-------------------------------------------------
PROBLEM: Script always picked from validated_weapons, ignoring stock WOTLK
REQUIRED: Prefer stock WOTLK weapons when skill is available in CSV

FIX IMPLEMENTED:
  - Updated validate_weapon_coverage() to accept both cursors:
    * source_cursor: Database to validate (dbc or original_dbc)
    * original_cursor: Stock WOTLK for weapon preference lookup
  - Load stock weapons for each race/class/gender before validation
  - Build stock_weapon_map of skills that match CSV requirements
  - Modified find_replacement() helper to check stock_weapon_map first
  - Updated main script to pass original_dbc_cursor to function

RESULT: ✅ Stock weapons preferred, minimizes changes from vanilla


ISSUE 3: Death Knight Weapon Detection
---------------------------------------
INVESTIGATION: User reported DKs showing as "only having Swords"
VERIFICATION:
  - Checked charstartoutfit: DKs have item 25 (Worn Shortsword) in slot 5
  - Item 25 is class 2 (weapon), subclass 7 (One-Handed Swords)
  - Script correctly detects weapon exists

RESULT: ✅ DK weapons detected correctly (may have been cosmetic reporting)
