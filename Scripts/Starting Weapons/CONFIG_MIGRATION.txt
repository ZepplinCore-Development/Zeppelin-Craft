================================================================================
NEW .env CONFIGURATION OPTIONS
================================================================================

# Death Knight Melee Weapons
ADD_DK_MELEE_WEAPONS=true

Values: true (add weapons), false (stock WOTLK behavior)
Default: true (custom QoL improvement)

# Ranged Weapon Classes
RANGED_ALLOWED_CLASSES=3,4

Format: Comma-separated class IDs
Default: 3,4 (Hunter, Rogue)
Example: 1,3,4 (add Warrior)

# Ranged Weapon Race/Class Combos
RANGED_ALLOWED_COMBOS=8:1

Format: race:class,race:class (comma-separated tuples)
Default: 8:1 (Troll Warrior)
Example: 8:1,5:2 (Troll Warrior + Undead Paladin)
