ISSUE 3: Stock weapon preference not implemented
================================================================================

SYMPTOM:
  Script always picks a weapon from validated_weapons dict
  Doesn't check if character already has a working weapon in stock WOTLK

REQUIRED BEHAVIOR:
  1. Check stock WOTLK charstartoutfit for this race/class/gender
  2. For each weapon slot in stock:
     - Is this weapon skill available in CSV for this character?
     - YES → Keep the stock weapon (use same item, same slot)
     - NO → Find replacement from CSV skills
  3. Only add NEW weapons if no stock weapon exists for that slot

PURPOSE:
  - Keeps character creation screen happy (familiar weapons)
  - Minimizes changes from stock WOTLK
  - Only changes weapons when CSV requires different skill

IMPLEMENTATION NEEDED:
  In validate_weapon_coverage() Pass 1:

  1. Load stock weapons for this outfit:
     stock_weapons = get_original_weapon_slots(original_cursor, acore_cursor,
                                                race_id, class_id, gender)

  2. For each stock weapon:
     - Check if skill_id in available_skill_ids
     - If YES: outfit_weapons[slot] = (skill_id, item_id)  # Keep stock
     - If NO: Find replacement and add to mismatches

  3. In Pass 2:
     - Check outfit_weapons dict (populated with stock weapons)
     - Only add weapon if type is missing

  This way stock weapons are preferred, fallback to validated_weapons only
  when stock skill is not in CSV.

ISSUE 4: Source cursor confusion
================================================================================

OBSERVATION:
  validate_weapon_coverage() takes source_cursor parameter
  In default mode: source_cursor = dbc_cursor (current DB)
  In --compare-to-stock: source_cursor = original_dbc_cursor (stock WOTLK)

  BUT for stock weapon preference (Issue 3), we need original_dbc access
  even in default mode!

SOLUTION:
  Pass BOTH cursors to validate_weapon_coverage():

  def validate_weapon_coverage(weapon_skills, current_cursor, original_cursor,
                                acore_cursor, validated_weapons):
      """
      current_cursor: The DB to validate (dbc or original_dbc)
      original_cursor: Stock WOTLK for weapon preference lookup
      """

  Update main script fix_starting_weapons.py:

  if compare_to_stock:
      validation_cursor = original_dbc_cursor
  else:
      validation_cursor = dbc_cursor

  # Pass BOTH cursors
  mismatches, weapon_additions = validate_weapon_coverage(
      weapon_skills,
      validation_cursor,        # What to validate
      original_dbc_cursor,      # For stock weapon preference
      acore_cursor,
      validated_weapons
  )
